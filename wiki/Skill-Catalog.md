# Skill catalog

| Skill | Role |
|-------|------|
| `six-sigma-master-black-belt` | Architecture DMAIC audit (structure, coupling, CTQs, first principles) |
| `ctq-charter` | Problem framing and Black Belt–ready project charter |
| `measurement-system` | Metric validity / instrumentation (software MSA) |
| `incident-rca` | Postmortem and recurring-defect root cause |
| `eng-value-stream` | Idea→prod delivery flow and process waste |
| `dfss-system-design` | Greenfield or major redesign from CTQs |
| `design-fmea` | Ranked design/process failure modes (RPN) |
| `controlled-experiment` | A/B, canary, holdback; ship/stop rules |
| `control-plan` | Hold-the-gains: fitness functions, owners, reaction plans |
| `a3-kaizen` | Small-scope A3 for one local pain point |

Each folder in the repo is copyable into `.cursor/skills/` or `~/.cursor/skills/`. Descriptions use distinct trigger phrases so auto-invoke stays focused.
